# Space Shooter

Play the game in your browser: <https://rehanmohammed2609.github.io/Space-shooter/>

## Controls

- Click the game to start and focus it.
- Move with **W**, **A**, **S**, and **D**.
- Hold **Space** to fire.

Survive enemy waves, avoid enemy ships and lasers, and keep your health and lives. Each cleared wave advances the level.

The game runs in the browser using WebAssembly. Like other client-side browser games, the playable build and assets are downloaded to your browser.
